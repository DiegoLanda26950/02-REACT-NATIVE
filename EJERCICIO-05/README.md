# Ejercicio 05 - Tarjeta de producto

## Qué he aprendido

- He aprendido a crear una tarjeta de producto con una imagen, textos, una valoración, un precio y un botón, y a colocar el precio y el botón en la misma fila usando `flexDirection: 'row'`.

## Respuesta a la pregunta de comprensión

¿Qué información debería tener mayor jerarquía visual: categoría, nombre del producto o precio?

Respuesta:

El nombre del producto debería destacar más porque es la información principal. Después estaría el precio y por último la categoría.

## Qué he modificado

He añadido una tarjeta para mostrar el producto, una imagen, la etiqueta de oferta, el nombre del producto, la valoración, el precio y un botón para añadirlo.

## Resultado

La interfaz ha quedado como una tarjeta de producto centrada, con un fondo oscuro y una tarjeta blanca. Dentro aparecen la imagen de los auriculares, la oferta, el nombre, la valoración, el precio y el botón AÑADIR.
