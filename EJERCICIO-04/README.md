# Ejercicio 04 - Pantalla de acceso

## Qué he aprendido
- He aprendido a crear una pantalla de acceso con Text, TextInput y Pressable, usar secureTextEntry para ocultar la contraseña y 
a crear una tarjeta para agrupar el formulario.

## Respuesta a la pregunta de comprensión
¿Por qué en este ejercicio no necesitamos todavía `useState`?

Respuesta:
Porque todavía no necesitamos guardar ni utilizar los datos que escribe el usuario. Solo estamos creando la parte visual de la pantalla

## Qué he modificado
He añadido una tarjeta (card) para agrupar el formulario, un campo para el correo electrónico, campo contraseña, un botón de inicio de sesión con Pressable, y los etilos de la pagina

## Resultado
La interfaz ha quedado como una pantalla de inicio de sesión, con un fondo oscuro y una tarjeta blanca centrada. Dentro de la tarjeta aparecen el título, los campos de correo y contraseña, el botón de inicio de sesión y el texto para registrarse.
