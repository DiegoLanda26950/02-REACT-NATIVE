# Ejercicio 01 - Mi primera pantalla

## Qué he aprendido

He aprendido a crear una pantalla básica con React Native, `StyleSheet` para aplicar estilos, los componentes `View` y `Text`, y acentrar los elementos de la pagina


## Respuesta a la pregunta de comprensión
Explica con tus palabras la diferencia entre el componente `View` y el componente `Text`.

Respuesta:
El componente `View` se utiliza como contenedor para organizar otros elementos de la pantalla, el `Text` se utiliza para mostrar texto en la aplicación.

## Qué he modificado
- Un contenedor principal con `View`.
- Título y un subtítulo.
- Texto del curso `Curso 2026/27`.
- Color de fonddo.
- Bordes redondeados y un borde alrededor del contenedor.
- He cambiado los tamaños, colores y estilos de los textos.

## Resultado
La interfaz ha quedado como una pantalla sencilla y centrada, con un fondo oscuro, un título destacado, un subtítulo y el curso en color azul. Los elementos están centrados horizontal y verticalmente.
